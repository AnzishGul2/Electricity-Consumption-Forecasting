# Electricity-Consumption-Forecasting
## Over View 
ML model to forecast electricity consumption of next week using the historical data of last 14 days . Built with XGBoost and Streamlit 
## Problem Statement
Enables utility companies and households to optimiz power generation 
## Tech Stack
- Language: Python
- Libraries: Pandas, NumPy, Scikit-learn, XGBoost
- Framework:Streamlit
- Deployment: Streamlit Cloud
